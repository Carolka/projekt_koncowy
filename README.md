# Katalog biblioteczny

Aplikacja do zarządzania katalogiem książek i rezerwacjami egzemplarzy.

## Technologie

- Python
- Django 5.2 LTS
- PostgreSQL 17
- Docker Compose

## Instalacja zależności

Utwórz środowisko wirtualne:

    python3 -m venv .venv

Aktywuj je na macOS/Linux:

    source .venv/bin/activate

Zainstaluj zależności:

    python -m pip install -r requirements.txt

Instrukcja konfiguracji bazy i uruchomienia aplikacji zostanie
uzupełniona w kolejnych etapach.
